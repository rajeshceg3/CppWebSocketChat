## Blocked, exactly
- `cmake -S . -B /tmp/chat-build` fails: `Could NOT find Boost (missing: Boost_INCLUDE_DIR system thread json)`.
- System has only Boost 1.74 runtime libraries (filesystem, iostreams, locale, thread; no headers, no system, no json) and the CMake recipe requires Boost >= 1.75 with system/thread/json.
- No /usr/include/boost, no /usr/include/openssl; no sudo/apt to install libboost-dev or libssl-dev. A conan-provided or privately built Boost 1.75+ (the skill's Launch section used a private Boost 1.83) is the documented unblock path; building Boost from source was judged too heavy for this sandbox.
